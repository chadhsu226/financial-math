2.1 現金流量的基礎概念

現金流量（Cash Flow）指的是在特定時間點上，資金的實際流入或流出。

  • 流入（Inflow，+）：代表資金進入，以正值表示。
  • 流出（Outflow，−）：代表資金支出，以負值表示。

準確辨識現金流的金額與發生時間點，是後續所有年金計算的基礎。

年金（Annuity）是指一系列金額相等且間隔時間相同的連續現金流。

2.3 年金的終值計算：普通年金終值

FVA = C × [(1 + r)n − 1] / r

每期期末存入 C，經過 n 期、每期利率 r 複利後的累積總額。

財務數學 / 第二章

期初年金終值

FVAD = C × [(1 + r)n − 1] / r × (1 + r)
FVAD = FVA × (1 + r)

期初年金的每一筆現金流都比普通年金多滾了一期利息，因此 FVAD 恆大於 FVA。

財務數學 / 第二章

範例演練 2.2：期初年金終值計算

小明每年年初存入 C = 10,000 元，年利率 r = 4%，為期 n = 8 年。

FVA = 10,000 × [(1.04)8 − 1] / 0.04 ≈ 92,142.26
FVAD = 92,142.26 × 1.04 ≈ 95,827.95
普通年金終值 FVA
92,142

95,828

8 年後，小明的儲蓄未來價值約為 95,827.95 元。

2.4 年金的現值計算：普通年金現值

PVA = C × [1 − (1 + r)−n] / r

把未來 n 期、每期 C 元的現金流，折現回今天的等值總額。

財務數學 / 第二章

期初年金現值與永續年金現值

PVAD = PVA × (1 + r)
PVP = C / r

永續年金現值只需要每期金額除以利率，因為現金流沒有終止的一天（n → ∞ 時，(1+r)−n → 0）。

財務數學 / 第二章

範例演練 2.3：房貸現值（普通年金）

小華每月能支付 C = 25,000 元房貸。年利率 1.8%，每月複利，還款期限 20 年。

每月利率 r = 0.018 / 12 = 0.0015，總期數 n = 20 × 12 = 240

PVA = 25,000 × [1 − (1.0015)−240] / 0.0015
PVA ≈ 5,035,591.07

也就是說，小華最多能申請到約 503.6 萬元的房貸。

公式選用總表

情境公式
普通年金終值FVA = C[(1+r)n−1]/r
期初年金終值FVAD = FVA × (1+r)
普通年金現值PVA = C[1−(1+r)−n]/r
期初年金現值PVAD = PVA × (1+r)
永續年金現值PVP = C / r

先判斷現金流發生在期初還是期末，再決定要不要多乘一次 (1+r)；月付款題目務必先把年利率與年數換算成月利率與月數。

綜合演練 6：個案思考（奧運金牌）

一次性領取 20,000,000 元，或每月領取 75,000 元、持續 50 年，年利率 2%（每月複利），哪個方案對你更有利？

顯示解答

每月利率 r = 0.02 / 12 ≈ 0.0016667，總期數 n = 600

PVA = 75,000 × [1 − (1 + r)−600] / r ≈ 28,431,639.24

分期方案的現值（約 2,843 萬元）高於一次領取的 2,000 萬元，在折現率相同、款項如期兌現的前提下，分期方案較為有利；但仍須考慮通貨膨脹、對方違約風險與資金流動性需求等因素。
