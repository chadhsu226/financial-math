Chapter 5: Capital Budgeting and Long-Term Investment Decisions

Introduction

This chapter is where financial mathematics meets real-world decision-making. Capital budgeting is the process by which firms plan and manage long-term investment projects. We will use NPV and IRR, among other metrics, to assess a project's financial viability and make sound resource-allocation decisions.

5.1 Net Present Value (NPV)

Core Concept

Net present value is the gold standard for evaluating project viability: it measures a project's net value today after discounting all of its future cash inflows and outflows.

$$NPV = \sum_{t=0}^{n} \frac{CF_t}{(1+r)^t}$$

1. NPV Decision Rule

  • If $NPV > 0$: the project is viable and will increase shareholder wealth.
  • If $NPV < 0$: the project is not viable and should be rejected.
  • If $NPV = 0$: the project only breaks even.

2. Worked Example 5.1: Calculating NPV

Scenario: An initial investment of $\$100{,}000$, with net inflows of $\$40{,}000$ per year for the next three years, at a cost of capital $r=10\%$.

$$NPV = -100{,}000 + \frac{40{,}000}{1.10} + \frac{40{,}000}{1.10^2} + \frac{40{,}000}{1.10^3} \approx -525.91$$

Decision: Since $NPV < 0$, the project is not viable and should be rejected.

5.2 Internal Rate of Return (IRR)

Core Concept

The IRR is the discount rate at which a project's NPV is exactly zero — it represents the annualized rate of return the project is expected to earn.

$$\sum_{t=0}^{n} \frac{CF_t}{(1+IRR)^t} = 0$$

Decision Rule

  • If $IRR > r$ (cost of capital): the project is viable.
  • If $IRR < r$ (cost of capital): the project is not viable.

Worked Example 5.2: Estimating and Applying IRR

Continuing Example 5.1, solving by trial and error:

$$IRR \approx 9.70\%$$

Decision: $IRR=9.70\% < r=10\%$, so the project is not viable — consistent with the NPV conclusion.

5.3 Supplementary Capital Budgeting Methods

1. Payback Period

  • Measures how long it takes to recover the initial investment.
  • Drawback: it ignores the time value of money.

2. Discounted Payback Period

  • Accounts for the time value of money by measuring how long it takes to recover the discounted value of the investment.

3. Worked Example 5.3: Calculating the Payback Period

Scenario: An initial investment of $\$250{,}000$, cost of capital $r=12\%$, with cash inflows over the next four years of $\$100{,}000$, $\$120{,}000$, $\$80{,}000$, and $\$50{,}000$.

$$Payback\ Period = 2 + \frac{30{,}000}{80{,}000} = 2.375 \text{ years}$$
$$Discounted\ Payback\ Period \approx 3.255 \text{ years}$$
