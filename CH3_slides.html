3.1 債券的基礎概念與現金流量

債券（Bond）是一種債務憑證。債券持有人享有兩種現金流：定期收到的利息（票息）與到期時收回的本金（面額）。

3.2 債券定價模型

Price = C × [1 − (1 + r)−n] / r + FV × (1 + r)−n

前半段是票息年金的現值，後半段是到期面額的現值，兩者相加就是債券的合理價格。

財務數學 / 第三章

範例演練 3.1：溢價債券定價

面額 FV = 100,000 元，票面利率 rc = 4%，每年付息，三年後到期（n = 3），市場利率 r = 3.8%。

票息 C = FV × rc = 100,000 × 4% = 4,000 元

Price = 4,000 × [1 − (1.038)−3] / 0.038 + 100,000 × (1.038)−3
Price ≈ 100,557.13 元（溢價債券）

因為票面利率（4%）高於市場利率（3.8%），投資人願意付出比面額更高的價格。

財務數學 / 第三章

溢價、折價與平價債券

利率條件債券狀態
rc > r溢價債券（Price > FV）
rc = r平價債券（Price = FV）
rc < r折價債券（Price < FV）

票面利率高於市場利率時，票息比市場上同等風險的投資更優渥，投資人願意以高於面額的價格買進。

3.3 債券價格與市場利率的關係（利率風險）

票息與面額在發行時就已固定，債券價格是用市場利率把它們折現而得：

  • 市場利率上升 → 折現率變大 → 債券價格下降
  • 市場利率下降 → 折現率變小 → 債券價格上升

因市場利率變動而使債券價格波動的風險，稱為利率風險。即使發行者不違約，到期前賣出仍可能虧損。

財務數學 / 第三章

範例 3.2 結論

  • 到期期限越長，利率風險越大：甲、乙票面利率相同，10 年期的跌幅接近 3 年期的 3 倍。
  • 票面利率越低，利率風險越大：同為 10 年期，零息債券的現金流全部集中在到期日，跌幅最大。

若利率反過來由 4% 降到 3%，乙債券上漲 8.53%，漲幅大於利率上升 1% 時的跌幅 7.72%。衡量利率敏感度的「存續期間」留待後續課程。

3.4 股票評價：股票的現金流量

股價＝未來現金流量的現值。股東的現金流量來自持有期間的股利與將來賣出的價格。

持有一年：年底收到股利 D₁，並以 P₁ 賣出：

P₀ = (D₁ + P₁) / (1 + r)

但 P₁ 又取決於 D₂ 與 P₂，P₂ 又取決於 D₃ 與 P₃……如此不斷往後推。

財務數學 / 第三章

股利折現模型（DDM）

一直往後推，賣出價格最終會被折現到幾乎為零，股價就等於未來所有股利的現值：

P₀ = D₁/(1+r) + D₂/(1+r)2 + D₃/(1+r)3 + ⋯

股票沒有到期日、未來股利也不確定，無法逐一預測，因此要對股利走勢做簡化假設：零成長或固定成長。

財務數學 / 第三章

特例一：零成長模型（永續年金）

若每年股利固定為 D、永不改變（g = 0），股利折現模型就是第二章的永續年金：

P₀ = D / r

適用於每年發放固定股利、沒有到期日的特別股。

財務數學 / 第三章

範例演練 3.3：特別股評價

某特別股每年年底固定發放股利 D = 5 元，沒有到期日。要求報酬率 r = 8%，合理價格為多少？

P₀ = 5 / 0.08 = 62.5 元

以 62.5 元買進、每年領 5 元，報酬率正好是 5 / 62.5 = 8%，與第二章範例 2.4 的獎學金基金會同一個道理。

財務數學 / 第三章

特例二：固定成長——高登成長模型（GGM）

股利每年以固定成長率 g 永續成長，即成長型永續年金：

P₀ = D₁ / (r − g) = D₀(1 + g) / (r − g)
  • 股利以固定的 g 永續成長。
  • r 必須大於 g，否則公式不成立。
  • 分子是 D₁：題目給剛發放的 D₀ 時，要先乘以 (1 + g)。
財務數學 / 第三章

範例演練 3.4：高登模型定價

某公司剛發放股利 D₀ = 2.00 元，g = 5%，r = 10%。

D₁ = 2.00 × 1.05 = 2.10 元
P₀ = 2.10 / (0.10 − 0.05) = 42 元
財務數學 / 第三章

要求報酬率的組成

把 GGM 移項：

r = D₁ / P₀ + g
  • D₁ / P₀：股利殖利率，來自股利的報酬。
  • g：資本利得率，在 GGM 下股價也以 g 成長，P₁ = P₀(1 + g)。

範例 3.4：2.10 / 42 = 5%，加上 g = 5%，合計 10% = r。P₁ = 42 × 1.05 = 44.10，(2.10 + 44.10) / 1.10 = 42。

財務數學 / 第三章

範例演練 3.5：r 與 g 變動的影響

延續範例 3.4（D₀ = 2.00 元）：

情境計算股價
原始：r = 10%，g = 5%2.10 / 0.0542 元
r 提高到 12%2.10 / 0.0730 元（−28.6%）
g 提高到 6%2.12 / 0.0453 元（+26.2%）

要求報酬率上升，股價下跌，與債券的利率風險同一個道理。分母 r − g 很小，r 或 g 小幅變動就會讓股價大幅改變。

財務數學 / 第三章

補充：模型的限制

  • 不發放股利的公司（例如許多科技成長股）無法直接套用股利折現模型。
  • 高速成長期的 g 可能暫時高於 r，需改用兩階段成長模型：先逐年折現高成長期股利，再以 GGM 計算穩定成長後的價值。
  • 實務上也常用本益比（P/E）等相對評價法與同業比較。
財務數學 / 第三章

公式選用總表

情境公式
債券定價Price = C[1−(1+r)−n]/r + FV(1+r)−n
零息債券Price = FV(1+r)−n（即 C = 0）

綜合演練 5

在其他條件相同下，利率風險對長期債券、短期債券或零息債券的影響何者最大？為什麼？

顯示解答

長期的零息債券最大。

  • 期限越長，現金流被折現的期數越多，對利率越敏感。
  • 零息債券的現金流全部集中在到期日，沒有提早回收的票息，所以比同期限的附息債券更敏感（範例 3.2：−9.13% 對 −7.72%）。

綜合演練 8

某股票市價 50 元，預期 D₁ = 2 元，股利每年永續成長 4%。隱含的要求報酬率為多少？股利殖利率與資本利得率各多少？

綜合演練 9

高登成長模型的主要假設為何？若股利成長率高於要求報酬率，能否使用 GGM？

顯示解答
  • 股利每期以固定成長率 g 永續成長。
  • 要求報酬率 r 必須大於 g，現值才會收斂。
  • 公司無限期持續經營並發放股利。

若 g ≥ r，分母 r − g ≤ 0，GGM 不適用，需改用兩階段成長模型等方法。

財務數學 / 第三章

本章重點整理

  • 債券價格 = 票息年金現值 + 面額現值；票面利率與市場利率的相對大小決定溢價／折價／平價。
  • 市場利率與債券價格呈反向關係（利率風險）；期限越長、票面利率越低，利率風險越大。
  • 股價 = 未來所有股利的現值；零成長用 P₀ = D/r（特別股），固定成長用 GGM P₀ = D₁/(r−g)，且需 r > g。
  • 要求報酬率 = 股利殖利率 + 資本利得率（r = D₁/P₀ + g）。完成以上九題練習並驗算。
