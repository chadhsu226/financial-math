財務數學 / 第五章

導言：什麼是資本預算？

規劃與評估長期投資專案的過程：買新設備、蓋廠房、開分店、推新產品線。

  • 特點：金額大、影響期間長、投入後很難反悔。
  • 支出在今天，回收分散在未來好幾年，必須用現值換算到同一時點才能比較。
  • 本章路線：現金流量與資本成本 → NPV → IRR → 回收期 → NPV 與 IRR 的衝突。
財務數學 / 第五章

5.1 投資專案的現金流量 CFt

時點現金流量正負號
t = 0（今天）期初投資：購買設備、裝修、前期費用流出，記為負
t = 1, …, n營運淨現金流量＝增加的現金收入 − 增加的現金支出通常為正
t = n（期末）殘值：設備變賣收入（若有）流入，記為正

與第二章相同：流入為正、流出為負；營運現金流量假設發生在每期期末。

財務數學 / 第五章

資本成本 r：一種機會成本

資本成本是公司對專案要求的最低報酬率，也是折現時使用的利率 r。

  • 它代表機會成本：錢不投入這個專案，改投資在風險相同的其他機會可賺到的報酬率。
  • 專案的報酬若連資本成本都達不到，不如把錢投到別的地方。
財務數學 / 第五章

財務數學 / 第五章

5.2 淨現值法（Net Present Value, NPV）

淨現值法是評估專案可行性的黃金標準，衡量一個專案未來所有現金流入和流出，經過折現後在今天的淨價值。

NPV = Σt=0n CFt / (1 + r)t
財務數學 / 第五章

NPV 決策準則

  • 若 NPV > 0：專案可行，將增加股東財富。
  • 若 NPV < 0：專案不可行，應予拒絕。
  • 若 NPV = 0：專案僅能打平成本。

財務數學 / 第五章

範例 5.1 解讀

  • 流入合計 120,000 元，換算成今天只值 99,474.08 元，低於烤箱價格 100,000 元。
  • NPV < 0：烤箱的報酬率略低於要求的 10%，不建議購買。
  • 敏感度：若每年淨流入提高到 41,000 元，NPV ≈ +1,960.93，決策反轉為購買。

NPV 對現金流量預估很敏感，實務上要謹慎估計。

財務數學 / 第五章

5.3 內部報酬率法（Internal Rate of Return, IRR）

IRR 是指使專案的 NPV 剛好等於零的折現率，也就是專案本身的年報酬率，可看成「損益兩平折現率」。

Σt=0n CFt / (1 + IRR)t = 0
  • 若 IRR > r（資本成本）：專案可行。
  • 若 IRR < r（資本成本）：專案不可行。
財務數學 / 第五章

NPV 曲線：IRR 在哪裡？

折現率越高，NPV 越低；曲線與 NPV＝0 的交點就是 IRR。r＝0% 時 NPV＝120,000 − 100,000＝20,000。

財務數學 / 第五章

範例演練 5.2：試誤法與內插法

  • r = 9%：NPV = 40,000 × [1 − (1.09)−3]/0.09 − 100,000 ≈ +1,251.79
  • r = 10%：NPV ≈ −525.92 → IRR 介於 9% 與 10% 之間
IRR ≈ 9% + 1,251.79 / (1,251.79 + 525.92) × 1% ≈ 9.70%

精確值約 9.701%。決策：IRR ≈ 9.70% < r = 10%，不建議購買，與 NPV 結論一致。

財務數學 / 第五章

NPV 與 IRR 的關係

  • 「先投入、後回收」的一般專案，NPV 曲線向右下方傾斜：IRR > r 與 NPV > 0 是同一件事。
  • 評估單一專案時，兩個準則結論一致。
  • 比較互斥專案時可能衝突；現金流量正負號多次改變時可能有多個 IRR（見 5.5）。

財務數學 / 第五章

5.4 資本預算的輔助方法：回收期法

投資回收期法（Payback Period）

  • 衡量收回初始投資成本所需的時間。
  • 缺點：忽略了貨幣的時間價值。

折現回收期法（Discounted Payback Period）

  • 考慮時間價值，衡量收回投資折現值所需時間。
財務數學 / 第五章

範例演練 5.3：回收期計算

初始投資 250,000 元，資本成本 r = 12%，未來四年現金流入分別為 100,000、120,000、80,000、50,000。

Payback Period = 2 + 30,000 / 80,000 = 2.375 年
Discounted Payback Period ≈ 3.255 年

前兩年累積流入 220,000，尚差 30,000 才回本，第三年流入 80,000，故回收期落在第三年的 0.375 處。

財務數學 / 第五章

課堂活動：回收期計算機

若累積現金流在專案存續期內都無法回本，計算機會顯示「未回本」。

財務數學 / 第五章

5.5 NPV 與 IRR 的衝突

單一專案時兩者結論一致；但在互斥專案（只能選一個）之間選擇時，可能意見不同。

  • 常見原因：專案規模不同，或現金流量的時間分布不同。
  • 原則：以 NPV 為準，因為它直接衡量股東財富的增量。
財務數學 / 第五章

決策優先順序：以 NPV 決策為準。

綜合演練 6

請解釋 NPV 和 IRR 的核心差異，並說明衝突時為何優先遵循 NPV 準則？

顯示解答

NPV 衡量的是專案創造的「絕對財富增量」（金額），而 IRR 衡量的是「相對報酬率」（百分比）。當比較規模差異很大的互斥專案時，IRR 較高的小規模專案，其創造的絕對財富可能遠低於 IRR 較低但規模較大的專案。由於企業決策的最終目標是最大化股東財富（金額），因此發生衝突時應以 NPV 為準。

財務數學 / 第五章

本章重點整理

  • 先畫現金流量時間線：期初投資為負、營運淨流入為正；資本成本 r 是機會成本，也是折現率。
  • NPV 是黃金標準：逐期折現後加總，NPV > 0 才可行，數值代表股東財富的增量。
  • IRR 是 NPV 曲線與橫軸的交點，可用試誤法＋內插法估算；IRR > r 才可行。
  • 回收期是輔助指標；互斥專案的 NPV 與 IRR 衝突時，一律以 NPV 為準。
