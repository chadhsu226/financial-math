財務數學 / 第五章

5.1 淨現值法（Net Present Value, NPV）

淨現值法是評估專案可行性的黃金標準，衡量一個專案未來所有現金流入和流出，經過折現後在今天的淨價值。

NPV = Σt=0n CFt / (1 + r)t
財務數學 / 第五章

NPV 決策準則

  • 若 NPV > 0：專案可行，將增加股東財富。
  • 若 NPV < 0：專案不可行，應予拒絕。
  • 若 NPV = 0：專案僅能打平成本。
財務數學 / 第五章

範例演練 5.1：NPV 計算

初始投資 100,000 元，未來三年每年淨流入 40,000 元，資本成本 r = 10%。

NPV = −100,000 + 40,000/1.10 + 40,000/1.102 + 40,000/1.103
NPV ≈ −525.92 元

決策：由於 NPV < 0，該專案不可行，應予拒絕。

財務數學 / 第五章

5.2 內部報酬率法（Internal Rate of Return, IRR）

IRR 是指使專案的 NPV 剛好等於零的折現率，代表專案預期可實現的年化回報率。

Σt=0n CFt / (1 + IRR)t = 0
  • 若 IRR > r（資本成本）：專案可行。
  • 若 IRR < r（資本成本）：專案不可行。
財務數學 / 第五章

範例演練 5.2：IRR 估算與應用

延續範例 5.1（初始投資 100,000 元，未來三年每年流入 40,000 元），透過試誤法／數值方法求解：

IRR ≈ 9.70%

決策：IRR = 9.70% < r = 10%，專案不可行，與 NPV 結論一致。

5.3 資本預算的輔助方法

投資回收期法（Payback Period）

  • 衡量收回初始投資成本所需的時間。
  • 缺點：忽略了貨幣的時間價值。

折現回收期法（Discounted Payback Period）

  • 考慮時間價值，衡量收回投資折現值所需時間。
財務數學 / 第五章

範例演練 5.3：回收期計算

初始投資 250,000 元，資本成本 r = 12%，未來四年現金流入分別為 100,000、120,000、80,000、50,000。

Payback Period = 2 + 30,000 / 80,000 = 2.375 年
Discounted Payback Period ≈ 3.255 年

前兩年累積流入 220,000，尚差 30,000 才回本，第三年流入 80,000，故回收期落在第三年的 0.375 處。

綜合演練 1

初始投資 250,000 元，未來四年流入：100,000、120,000、80,000、50,000，資本成本 12%。NPV 是多少？

顯示解答
NPV = −250,000 + 100,000/1.12 + 120,000/1.122 + 80,000/1.123 + 50,000/1.124
NPV ≈ 23,667.30 元

NPV > 0，專案可行。

綜合演練 2

承接上題，投資回收期是多少年？

顯示解答

累積流入：第1年100,000；第2年220,000；第3年300,000。

財務數學 / 第五章

綜合演練 3

請解釋 NPV 和 IRR 的核心差異，並說明衝突時為何優先遵循 NPV 準則？

顯示解答

NPV 衡量的是專案創造的「絕對財富增量」（金額），而 IRR 衡量的是「相對報酬率」（百分比）。當比較規模差異很大的互斥專案時，IRR 較高的小規模專案，其創造的絕對財富可能遠低於 IRR 較低但規模較大的專案。由於企業決策的最終目標是最大化股東財富（金額），而非追求最高的報酬率百分比，因此發生衝突時應以 NPV 為準。

財務數學 / 第五章

綜合演練 4

初始投資 50,000 元，每年年底淨流入 15,000 元，持續 5 年，IRR 約為多少？（提示：介於 12% 至 15%）

顯示解答

令 IRR = r，使 −50,000 + 15,000 × [1−(1+r)−5]/r = 0。

以試誤法／數值方法求解，可得 IRR ≈ 15.24%

本章重點整理

  • NPV 是評估專案可行性的黃金標準：NPV > 0 才可行，數值代表股東財富的絕對增量。
  • IRR 是使 NPV 為零的折現率，須與資本成本比較，IRR > r 才可行。
  • 投資回收期與折現回收期是輔助指標，能快速衡量資金回收速度，但不能取代 NPV 作為主要決策依據。
  • 當互斥專案的 NPV 與 IRR 結論衝突時，一律以 NPV 為準，因為它直接衡量股東財富的增量。
