6.1 報酬率的衡量與預期（Expected Return）

R̄ = Σi=1n Pi × Ri

預期報酬率就是把每個可能情境的報酬率，依照發生機率加權平均。

衰退0.3−5%−0.015
總和1.00.085（8.5%）

6.2 風險的量化：變異數與標準差

σ² = Σi=1n Pi × (Ri − R̄)²
σ = √σ²

變異數衡量報酬率偏離預期值的平方期望值；標準差則把單位轉回與報酬率相同的百分比，較容易解讀。

財務數學 / 第六章

範例演練 6.2：風險計算（資產 A）

延續範例 6.1，R̄A = 8.5%：

σ²A = 0.3×(0.20−0.085)² + 0.4×(0.10−0.085)² + 0.3×(−0.05−0.085)²
σ²A = 0.009525
σA = √0.009525 ≈ 9.76%

6.3 投資組合與分散風險（Portfolio Theory）

投資組合預期報酬率

R̄P = Σj=1m wj × R̄j

投資組合變異數（雙資產）

σ²P = w²Aσ²A + w²Bσ²B + 2wAwBσAσBρAB
財務數學 / 第六章

相關係數（ρAB）的意義

ρAB = CovAB / (σA × σB)
  • ρAB = +1.0：完全同向變動，無法分散風險。
  • ρAB = −1.0：完全反向變動，可完全消除風險（在特定權重下）。
  • ρAB = 0：資產無關，具有顯著的分散效果。
財務數學 / 第六章

分散效果示例

兩資產各佔 50%（皆與資產 A 同分佈），ρAB = 0（完全獨立）：

σ²P = 0.5² × 0.009525 + 0.5² × 0.009525 + 0 = 0.0047625
σP = √0.0047625 ≈ 6.90% < σA = 9.76%

在保持預期報酬 8.5% 不變的情況下，風險從 9.76% 降低到 6.90%，證明了分散風險的有效性。

資產 B 權重會自動設為 1 − wA。試著把 ρ 從 0 拉到 −1，觀察組合標準差如何下降。

公式選用總表

情境公式
預期報酬率R̄ = Σ PiRi
變異數σ² = Σ Pi(Ri−R̄)²
標準差σ = √σ²
組合預期報酬R̄P = Σ wjR̄j
組合變異數（雙資產）σ²P = w²Aσ²A+w²Bσ²B+2wAwBσAσBρAB

相關係數 ρ 愈接近 −1，分散風險的效果愈明顯；ρ = +1 時完全沒有分散效果。

綜合演練 1

資產 A 的預期報酬率為 20%（機率 0.6）和 −10%（機率 0.4）。R̄A 是多少？

顯示解答
R̄A = 0.6 × 20% + 0.4 × (−10%) = 8.00%
財務數學 / 第六章

綜合演練 2

延續第 1 題，計算 σ²A 和 σA。

顯示解答
σ²A = 0.6×(20%−8%)² + 0.4×(−10%−8%)² = 0.0216
σA = √0.0216 ≈ 14.70%
財務數學 / 第六章

綜合演練 3

投資組合 P：70% 投資於 R̄A=8% 的資產 A，30% 投資於 R̄B=5% 的資產 B。R̄P 是多少？

顯示解答
R̄P = 0.7 × 8% + 0.3 × 5% = 7.10%
財務數學 / 第六章

綜合演練 4

延續第 3 題，σA=14.70%、σB=10%、ρAB=+1.0，σP 是多少？

顯示解答
σ²P = 0.7²×14.70%² + 0.3²×10%² + 2×0.7×0.3×14.70%×10%×1.0 = 1.7649%
σP = √1.7649% ≈ 13.29%

ρ=+1 時，σP 剛好等於各資產標準差的加權平均（0.7×14.70%+0.3×10%=13.29%），完全沒有分散效果。

財務數學 / 第六章

綜合演練 5

延續第 3 題，若 ρAB=−1.0，σP 是多少？

顯示解答
σ²P = 0.7²×14.70%² + 0.3²×10%² + 2×0.7×0.3×14.70%×10%×(−1.0) = 0.5314%
σP = √0.5314% ≈ 7.29%

相關係數愈負，分散效果愈強；當 ρ=−1 時風險降幅最大。

財務數學 / 第六章

綜合演練 6

在計算投資組合總風險時，哪個因子衡量兩資產變動的關聯性？若為負值，對整體風險有何影響？

顯示解答

衡量兩資產變動關聯性的因子是相關係數 ρAB（或共變異數 CovAB）。當 ρAB 為負值時，代表兩資產報酬率傾向反向變動：一個上漲時另一個容易下跌。這會使投資組合變異數公式中的交叉項（2wAwBσAσBρAB）變成負數，抵銷部分個別資產的風險，因此整體投資組合的風險（標準差）會比任一資產單獨持有時更低，這正是分散投資的核心原理。

財務數學 / 第六章

本章重點整理

  • 預期報酬率是各情境報酬率的機率加權平均；變異數與標準差則衡量報酬率偏離預期值的程度（風險）。
  • 標準差比變異數更實用，因為它的單位與報酬率相同，較容易直接解讀與比較。
  • 投資組合的風險不只取決於個別資產的風險，也取決於資產之間的相關係數：相關係數愈低（尤其接近 −1），分散風險的效果愈明顯。
  • 完成以上六題練習，並嘗試用投資組合分散模擬器驗證 ρ 對組合風險的影響方向。
