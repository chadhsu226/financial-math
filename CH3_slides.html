3.1 債券的基礎概念與現金流量

債券（Bond）是一種債務憑證。債券持有人享有兩種現金流：定期收到的利息（票息）與到期時收回的本金（面額）。

3.2 債券定價模型

Price = C × [1 − (1 + r)−n] / r + FV × (1 + r)−n

前半段是票息年金的現值，後半段是到期面額的現值，兩者相加就是債券的合理價格。

財務數學 / 第三章

範例演練 3.1：溢價債券定價

面額 FV = 100,000 元，票面利率 4%，每年付息，三年後到期（n = 3），市場利率 r = 3.8%。

票息 C = 100,000 × 4% = 4,000 元

Price = 4,000 × [1 − (1.038)−3] / 0.038 + 100,000 × (1.038)−3
Price ≈ 100,557.13 元（溢價債券）

因為票面利率（4%）高於市場利率（3.8%），投資人願意付出比面額更高的價格。

財務數學 / 第三章

3.3 債券價格與市場利率的關係（利率風險）

債券的價格與市場利率之間存在反向關係：

  • 市場利率上升 → 債券價格下降
  • 市場利率下降 → 債券價格上升
比較債券狀態
票面利率 > 市場利率溢價債券（Price > FV）
票面利率 = 市場利率平價債券（Price = FV）
票面利率 < 市場利率折價債券（Price < FV）

3.4 股票評價與高登成長模型（GGM）

高登成長模型（Gordon Growth Model, GGM）假設股利將以固定的速度（g）永續成長，並把這一串無限成長的現金流折現回今天的價值。

模型成立的前提是 r > g，否則現值會發散，公式不再適用。

財務數學 / 第三章

GGM 定價公式

P₀ = D₁ / (r − g)

其中 D₁ = D₀ × (1 + g)；r 為要求報酬率；g 為股利永續成長率。

財務數學 / 第三章

範例演練 3.2：高登模型定價

D₀ = 2.00 元，g = 5%，r = 10%。

D₁ = 2.00 × 1.05 = 2.10 元
P₀ = 2.10 / (0.10 − 0.05) = 42 元
財務數學 / 第三章

課堂活動：GGM 股票評價計算機

若 r ≤ g，模型不適用，計算機會提示錯誤。

財務數學 / 第三章

公式選用總表

情境公式
債券定價Price = C[1−(1+r)−n]/r + FV(1+r)−n
零息債券Price = FV(1+r)−n（即 C = 0）
高登成長模型P₀ = D₁/(r−g) = D₀(1+g)/(r−g)

零息債券只是把債券定價公式中的票息 C 設為 0；GGM 只在 r > g 時才有意義。

財務數學 / 第三章

綜合演練 4

當票面利率大於市場利率時，債券價格會如何？

顯示解答

溢價（Price > 面額）

因為投資人每期收到的票息高於市場要求的報酬，願意付出超過面額的價格購買，直到整體報酬率被拉回市場利率水準為止。

財務數學 / 第三章

綜合演練 5

高登成長模型的主要假設為何？

顯示解答
  • 股利每期以固定成長率 g 永續成長，不會中斷或改變成長率。
  • 要求報酬率 r 必須大於成長率 g（r > g），現值才會收斂。
  • 公司會無限期持續經營並發放股利。
財務數學 / 第三章

本章重點整理

  • 債券價格 = 票息年金現值 + 面額現值；票面利率與市場利率的相對大小決定溢價／折價／平價。
  • 市場利率與債券價格呈反向關係，這就是「利率風險」。
  • 高登成長模型把「股利永續成長」的現金流折現成一個簡單公式 P₀=D₁/(r−g)，但只在 r>g 時成立。
