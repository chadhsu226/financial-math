1.1 單利

利息僅依原始本金計算。利率固定時，每年的利息金額維持不變。

I = P × r × n
FV = P + I = P(1 + rn)

本金8,000元，年利率5%，每年利息恆為400元。

財務數學 / 第一章

單利計算範例

本金：8,000元。年利率：5%。期間：4年。

I = 8,000 × 0.05 × 4 = 1,600
FV = 8,000 + 1,600 = 9,600

若存款期間為半年，n應使用0.5，而非6。

I = 8,000 × 0.05 × 0.5 = 200

複利頻率與每期利率

FV = P(1 + r / m)mn
  • r為名目年利率，m為每年複利次數。
  • 每期利率 = r / m；總期數 = mn。
  • 名目年利率5%、按月複利、期間4年：每期利率為0.05/12，總期數為48期。

1.4 名目年利率與有效年利率

  • 名目年利率r：須搭配m才能決定每期利率。
  • 有效年利率（EAR）：計入複利效果後，一年期間實際的成長率。
  • EAR與實質利率不同，後者已扣除通貨膨脹的影響。
EAR = (1 + r / m)m − 1
財務數學 / 第一章

範例1.3 名目利率12%，按月複利

r / m = 0.12 / 12 = 0.01
EAR = 1.0112 − 1 = 12.6825%

每月以1%複利，一年下來約可產生12.68%的成長。

若為連續複利：EAR = eʳ − 1。

財務數學 / 第一章

將EAR換算為月利率

當報價的利率為EAR時，直接除以12並不等於等值的月利率。

imonth = (1 + EAR)1/12 − 1
EAR = 12%　⇒　imonth ≈ 0.9489%

請區分不同的報價方式：名目年利率12%按月複利，代表每月利率為1%；EAR為12%，則代表每月利率約為0.9489%。

財務數學 / 第一章

公式選用與常見錯誤提醒

情境公式
單利FV = P(1 + rn)
年複利FV = P(1 + r)n
每年m期複利FV = P(1 + r/m)mn
折現PV = FV/(1 + r)n
比較一年期成長率EAR = (1 + r/m)m − 1

請先將百分比換算為小數，並使利率與期數單位一致，且僅在最終結果四捨五入。

習題8 折現的意義

下列哪個概念與折現的關係最直接：複利、機會成本，還是通貨膨脹？

顯示解答與計算過程

機會成本

折現率反映的是資金若運用於其他類似機會所能獲得的報酬。即使沒有通貨膨脹，放棄今天動用資金的機會本身就是一種成本。
