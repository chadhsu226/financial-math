財務數學 / 第四章

4.1 貸款還款金額的確定

貸款本金總額（PV）本質上就是未來一系列等額還款（普通年金 C）在今天的現值總和。因此可利用普通年金現值公式反推每期還款金額 C。

財務數學 / 第四章

貸款還款金額公式

C = PV × r / [1 − (1 + r)−n]

把普通年金現值公式 PV = C × [1−(1+r)−n]/r 反過來解 C 即得此式。

財務數學 / 第四章

範例演練 4.1：房貸月付金計算

貸款 3,000,000 元，年利率 2.4%，每月複利，還款期限 20 年（240 個月）。每個月需償還多少？

每期利率 r = 2.4% / 12 = 0.002，總期數 n = 240

C = 3,000,000 × 0.002 / [1 − (1.002)−240]
C ≈ 15,751.34 元

財務數學 / 第四章

4.2 貸款攤銷表（Amortization Schedule）

貸款攤銷表詳細記錄每期還款如何拆解為利息和本金。在定額還款模式下，由於本金逐漸減少，每期利息遞減，而本金償還遞增。

  • 當期利息：Interestt = 期初餘額 × r
  • 本金償還：Principalt = C − Interestt
  • 期末餘額：期末餘額t = 期初餘額t − Principalt

財務數學 / 第四章

4.3 貸款未償餘額的計算

第 k 期結束後的未償餘額，等於剩下所有 (n−k) 期還款的現值總和：

OLBk = C × [1 − (1 + r)−(n−k)] / r

這是「現值法」：把尚未償還的未來付款，重新折現回第 k 期當下。

財務數學 / 第四章

範例演練 4.3：計算剩餘餘額

延續範例 4.1，在繳款滿 5 年（k = 60 期）後，剩餘貸款餘額是多少？

OLB60 = 15,751.34 × [1 − (1.002)−180] / 0.002
OLB60 ≈ 2,379,025.69 元

雖然已繳了 5 年，但只償還了約 620,974.31 元本金，體現了貸款初期大部分還款用於支付利息的現象。

計算機會先用 PV、r、N 反推每期還款金額 C，再算出第 k 期的利息、本金與期末餘額 OLB。

財務數學 / 第四章

公式選用總表

情境公式
還款金額C = PV × r / [1−(1+r)−n]
當期利息Interestt = 期初餘額 × r
當期本金Principalt = C − Interestt
未償餘額OLBk = C × [1−(1+r)−(n−k)]/r

還款金額公式其實就是年金現值公式反推 C；未償餘額公式則是把剩餘期數的年金現值再算一次。

財務數學 / 第四章

綜合演練 1

企業貸款 1,500,000 元，年利率 4.8%，每月複利，還款期 5 年。月付金為多少？第一期利息與本金各為多少？

顯示解答

r = 4.8%/12 = 0.004，N = 60

C = 1,500,000 × 0.004 / [1 − (1.004)−60] ≈ 28,169.61 元

第一期利息 = 1,500,000 × 0.004 = 6,000.00 元

第一期本金 = 28,169.61 − 6,000.00 = 22,169.61 元

財務數學 / 第四章

綜合演練 2

小陳借 800,000 元，10 年期，年利率 6%，每年還款一次。年付金為多少？繳完第 4 年後剩餘未償餘額為多少？

顯示解答
C = 800,000 × 0.06 / [1 − (1.06)−10] ≈ 108,694.37 元
OLB4 = 108,694.37 × [1 − (1.06)−6] / 0.06 ≈ 534,485.45 元
財務數學 / 第四章

綜合演練 3

請說明貸款攤銷表的原理，為何等額還款中利息部分會逐漸減少？

顯示解答

因為每期利息是「期初餘額 × r」計算出來的，而每期還款會先償還當期利息，剩下的部分才拿去償還本金。由於本金餘額會隨每次還款而減少，之後每一期的利息基礎（期初餘額）也跟著變小，所以在還款總額固定不變的前提下，利息占比會逐期下降，本金占比則逐期上升。

財務數學 / 第四章

綜合演練 4

5,000,000 元，25 年期，年利率 3%，每月還款。貸款滿 10 年後總共支付了多少利息？

顯示解答

r = 3%/12 = 0.0025，N = 300，k = 120

C = 5,000,000 × 0.0025 / [1 − (1.0025)−300] ≈ 23,710.57 元

10 年共繳款 23,710.57 × 120 ≈ 2,845,267.88 元

OLB120 ≈ 3,433,419.64 元，已償還本金 ≈ 5,000,000 − 3,433,419.64 = 1,566,580.36 元

總利息 ≈ 2,845,267.88 − 1,566,580.36 ≈ 1,278,687.53 元
財務數學 / 第四章

本章重點整理

  • 貸款還款金額 C 是把年金現值公式反過來解，讓未來所有等額還款的現值總和等於貸款本金。
  • 攤銷表顯示每期還款如何拆解為利息與本金：利息隨餘額遞減，本金隨之遞增，但每期還款總額不變。
  • 未償餘額 OLB 可視為「剩餘期數的年金現值」，用來計算任一時點提前還款或再融資時應償還的金額。
